# Dataset Sources and Download Guidance

This document summarizes the datasets referenced by the project. Downloads are NOT performed automatically to respect licensing and usage terms.

## EMBER (Portable Executables)
- **URL**: https://github.com/elastic/ember
- **License**: Creative Commons Attribution-ShareAlike 4.0 International (CC BY-SA 4.0)
- **How to obtain**: Follow the instructions in the repository to download feature CSVs or the full dataset. Place extracted contents under `data/ember/`.
- **Notes**: Suitable for training PE-focused models; be mindful of license when redistributing.

## MalwareBazaar (Metadata)
- **URL**: https://bazaar.abuse.ch/
- **License**: Requires acceptance of terms of use; API provides metadata and hashes.
- **How to obtain**: Use the public API with proper terms acceptance to download metadata or hashes. Store retrieved JSON/CSV in `data/malwarebazaar/`.
- **Notes**: Do not download or store malicious binaries here. Keep only metadata and hashes by default.

## BODMAS (Malware Dataset)
- **URL**: https://www.kaggle.com/datasets/mahyarelsayad/bodmas
- **License**: Subject to Kaggle terms; user must accept competition/dataset rules.
- **How to obtain**: After accepting terms, download via Kaggle CLI or web and place archives under `data/bodmas/`. Do not commit raw data.

## Synthetic Demo Dataset
- **Description**: Reproducible synthetic tabular features generated by `src/models/synthetic_data_generator.py`.
- **How to obtain**: Run `python -m src.models.train --config configs/train.yaml` to generate synthetic data used for training the demo model. Artifacts will be stored under `models/<version>/` and metrics at `models/metrics.json`.
- **Notes**: This is the safest default for demos; no real malware content is involved.

## Usage Policy
- Data directories are created by running `python -m src.data_collection.downloader`, which writes README.txt files with source information and licensing reminders.
- Raw binaries are not stored by default. Use hashes and metadata wherever possible.
- Ensure you have the rights to download and process any dataset before use.
